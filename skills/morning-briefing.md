# Скилл: утренняя сводка

Тип: рутина — последовательность шагов, использующая другие скиллы.

## Шаги

1. Прочитай `skills/weather.md` (`cat skills/weather.md`) и выполни инструкцию оттуда для города, который
   назвал пользователь (если город не назван — спроси, для какого города нужна сводка, не угадывай).
2. Прочитай `skills/email.md` (`cat skills/email.md`) и выполни инструкцию оттуда, чтобы узнать количество
   непрочитанных писем и их темы.
3. Собери короткую сводку на русском языке из двух частей: погода и почта. Если какой-то из шагов вернул
   ошибку или "не настроено" — так и напиши в этой части сводки, не пропускай молча и не выдумывай данные
   вместо реального результата.

## Пример итогового ответа

```
Погода в Минске: +18°C, слабый ветер, без осадков.
Почта: 3 непрочитанных письма (от boss@example.com "Отчёт", ...).
```
