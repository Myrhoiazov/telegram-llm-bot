Description: Используй, когда пользователь просит утреннюю сводку / общую сводку, объединяющую погоду и
почту. Это рутина, которая последовательно вызывает скиллы weather и email.

# Скилл: утренняя сводка

Тип: рутина — последовательность шагов, использующая другие скиллы.

## When to Use

✅ Используй этот скилл, когда пользователь просит:

- "Дай сводку на утро"
- "Что у меня сегодня?"
- "Сводка" / "briefing"

## When NOT to Use

❌ Не используй этот скилл, если нужна только погода или только почта по отдельности — тогда используй
соответствующий скилл напрямую (`skills/weather/SKILL.md` или `skills/email/SKILL.md`), не запускай всю
рутину целиком.

## Steps

1. Прочитай `skills/weather/SKILL.md` (`cat skills/weather/SKILL.md`) и выполни инструкцию оттуда для
   города, который назвал пользователь (если город не назван — спроси, для какого города нужна сводка, не
   угадывай).
2. Прочитай `skills/email/SKILL.md` (`cat skills/email/SKILL.md`) и выполни инструкцию оттуда, чтобы
   узнать количество непрочитанных писем и их темы.
3. Собери короткую сводку на русском языке из двух частей: погода и почта. Если какой-то из шагов вернул
   ошибку или "не настроено" — так и напиши в этой части сводки, не пропускай молча и не выдумывай данные
   вместо реального результата.

## Пример итогового ответа

```
Погода в Минске: +18°C, слабый ветер, без осадков.
Почта: 3 непрочитанных письма (от boss@example.com "Отчёт", ...).
```
