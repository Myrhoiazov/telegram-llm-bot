Description: Используй для вопросов о почтовом ящике: непрочитанные письма, новые письма, заголовки,
краткое содержание входящих и ручная triage-сводка. Это живые данные внешнего IMAP-сервера: получай их
только через execute_command.

# Скилл: почта через IMAP

Работай через `execute_command` и готовые скрипты в `skills/email/scripts/`. Не вставляй большой
Python-код в команду вручную: скрипты уже декодируют MIME-заголовки вида `=?UTF-8?...?=`, разворачивают
перенесённые заголовки и не помечают письма прочитанными.

## Когда использовать

Используй этот скилл, когда пользователь просит:

- проверить электронную почту, Gmail или входящие;
- сказать, сколько есть непрочитанных или новых писем;
- показать отправителей/темы непрочитанных писем;
- кратко разобрать непрочитанные письма и предложить triage-решения.

Для этих запросов сначала вызови `execute_command`. Не отвечай, что доступа к почте нет, пока команда
не вернула ошибку доступа.

## Инфраструктурные границы

Доступно:

- чтение `INBOX` через IMAP SSL;
- поиск непрочитанных писем;
- чтение заголовков и безопасного текстового фрагмента через `BODY.PEEK`;
- triage-сводка в ответе пользователю.

Недоступно:

- создание Gmail-черновиков;
- отправка писем;
- надёжное управление Gmail-метками `INBOX`, `UNREAD`, `SPAM`;
- использование Gmail API.

Если пользователь просит создать черновик, отправить ответ, переместить письмо в спам или изменить метки,
объясни, что текущий IMAP-скилл этого не делает. Можно предложить текст черновика в ответе, но не
утверждай, что он сохранён в Gmail.

## Конфигурация

Переменные окружения должны быть заданы в `.env` бота и передаются в `execute_command`:

- `EMAIL_IMAP_HOST`
- `EMAIL_IMAP_PORT` (обычно `993`)
- `EMAIL_ADDRESS`
- `EMAIL_APP_PASSWORD`

Если команда выводит `email_not_configured`, скажи пользователю, что почта не настроена. Если IMAP
возвращает ошибку логина, кратко перескажи ошибку без домыслов.

## Команды

Для "есть новые письма?" или "сколько непрочитанных?":

```bash
python3 skills/email/scripts/count_unread.py
```

Для "покажи новые письма" или "какие непрочитанные письма?":

```bash
python3 skills/email/scripts/list_unread_headers.py
```

Для "разбери почту", "что важное?", "сделай triage":

```bash
python3 skills/email/scripts/triage_unread.py
```

## Формат ответа

Для обычной проверки ответь кратко:

```text
Непрочитанных писем: <N>.
```

Если выводишь список, не показывай сырые MIME-строки `=?UTF-8?...?=`. Используй уже декодированные поля
из вывода скрипта:

```text
Непрочитанных писем: <N>.

1. From: ...
   Subject: ...
   Date: ...
```

Для triage-сводки по каждому письму укажи:

- отправителя;
- тему;
- категорию: `вероятный спам`, `может требовать ответа`, `информационное` или `неясно`;
- короткую причину классификации;
- предлагаемый следующий шаг.
