# Скилл: погода (wttr.in)

Тип: инструкция к публичному API, без авторизации.

## Как использовать

Выполни через execute_command:

```
curl -s wttr.in/<город>?0
```

- `<город>` — латиницей или транслитом, например `Minsk`, `Moscow`, `Berlin`. Пробелы заменяй на `+`.
- `?0` — компактный однострочный формат: температура, ветер, осадки.
- Если нужен более подробный вывод на несколько дней, убери `?0` и используй `?2` (сокращённый формат) или просто `curl -s wttr.in/<город>` для полной ASCII-сводки.
- Таймаут запроса ограничен таймаутом execute_command — если wttr.in не отвечает, сообщи пользователю,
  что сервис погоды сейчас недоступен, вместо того чтобы придумывать данные.

## Пример

```
curl -s wttr.in/Minsk?0
```
